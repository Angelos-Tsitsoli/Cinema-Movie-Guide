
# 🎬 Cinema Guide

A mobile app that shows which movies are currently playing at a specific cinema. Browse the list, tap a poster to see it enlarged, or tap a card to read the full details: description, director, cast, genre, duration, language and age rating.

The movie data is collected automatically by a Python scraper, stored in Supabase, and read by the app.

## Features

- List of the movies currently playing, with poster, director, duration, genre and a short description
- Tap a poster to view it large, centered and in front
- Tap a card to open the full movie details
- Movies that leave the cinema's program are hidden automatically
- Runs in the browser and as an Android app

## How it works

```
foivoscinema.gr  ──►  Python scraper  ──►  Supabase (movies table)  ──►  React app  ──►  Android (Capacitor)
```

1. The **scraper** reads the "now playing" page, opens each movie page, and collects the details.
2. It **upserts** the movies into the Supabase `movies` table, using the movie link as the unique key. Running it again updates existing rows and never creates duplicates, and movies that disappeared from the site are marked `is_playing = false`.
3. The **app** reads the table with Supabase's public (anon) key and shows the movies that are playing.

## Database

Table `movies`:

| Column | Type | Notes |
|---|---|---|
| `id` | bigint | primary key |
| `title` | text | |
| `link` | text | unique, used for upserts |
| `director` | text | |
| `cast_list` | text | |
| `genre` | text | |
| `duration` | text | |
| `language` | text | |
| `rating` | text | |
| `description` | text | short summary |
| `image` | text | poster URL |
| `is_playing` | boolean | `false` when the movie leaves the program |
| `updated_at` | timestamptz | |

Row Level Security is enabled with a read-only policy, so the app's public key can read the table but not change it.

## Getting started

### 1. The app

```bash
npm install
```

Create a `.env` file in the project root (next to `package.json`):

```
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-or-publishable-key
```

Use the public **anon/publishable** key here, never the secret key. Then start the dev server:

```bash
npm run dev
```

### 2. The scraper

Create a virtual environment and install the packages:

```bash
python -m venv venv
venv\Scripts\activate          # Windows (cmd)
source venv/Scripts/activate   # Windows (Git Bash)
source venv/bin/activate       # macOS / Linux

pip install requests beautifulsoup4 supabase python-dotenv
```

Create a `.env` file next to the scraper script:

```
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_SERVICE_KEY=your-secret-key
```

The secret key can write to the database, so keep it private and never put it in the app. Run the scraper whenever you want to refresh the movies:

```bash
python foivos_scraper.py
```

### 3. The Android app

Run these in the project root:

```bash
npm run build
npx cap sync
```

Then open the `android` folder in Android Studio and press **Run**, with an emulator or a phone with USB debugging turned on. To get an installable file, use **Build → Generate App Bundles or APKs → Generate APKs**.

After every code change, repeat `npm run build` and `npx cap sync` before running again.

## Notes

- Never commit `.env` files. Add them to `.gitignore`.
- The scraper depends on the structure of foivoscinema.gr. If the site changes its layout, the scraper may need small updates.
- Movie data and poster images belong to their respective owners and come from the cinema's public website.
- Possible next steps: showtimes per movie, a daily scheduled scraper run (for example with GitHub Actions), and more cinemas.
